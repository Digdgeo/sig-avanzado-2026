¿Puede este navegador con GeoLibre?

Comprobando…Si este mensaje no cambia, el navegador es demasiado antiguo para ejecutar la prueba.
RequisitoEstado

Si sale en rojo en Ubuntu: descarga Firefox actual en tu carpeta personal (no necesita permisos):
cd ~ && wget -O firefox.tar.xz "https://download.mozilla.org/?product=firefox-latest-ssl&os=linux64&lang=es-ES" && tar -xJf firefox.tar.xz && ~/firefox/firefox -P --no-remote
y abre este archivo otra vez con ese Firefox.
